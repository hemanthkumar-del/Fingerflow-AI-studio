# FingerFlow Studio Roadmap

## Version 1.1 (The Collaboration Update)
- **Real-time Multiplayer**: WebRTC and WebSockets integration to draw with friends simultaneously.
- **Shared Cursors & Hands**: See where others are pointing on the canvas.
- **Voice Commands**: Trigger tools and exports by saying "Switch to eraser" or "Export to PDF".
- **Presentation Mode**: A clean UI mode for teachers and presenters.

## Version 2.0 (The AI Ecosystem)
- **AI Copilot**: A proactive conversational assistant living directly on the canvas to help you brainstorm.
- **Community Templates**: Share your `.ffstudio` projects and custom brushes on a community hub.
- **Plugin Marketplace**: Easily install 3rd-party Brushes, Shapes, and Gestures directly from the UI.
- **AI Generators**: Text-to-Image generation bounded to selected canvas regions.

## Version 3.0 (Cross-Platform)
- **Mobile Web App**: Touch and gesture support optimized for tablets.
- **Native Desktop Apps**: Packaged with Electron/Tauri for offline local-first usage.
- **Custom Hardware Support**: Support for Wacom tablets and Apple Pencil alongside webcam gestures.
